Stock API

Stock API contains information about client defined items for product configuration

Stock products

GET /rest/v1.8.0/stock

  • Description
  • Data format
  • Try it
Returns client defined stock products
Input parameters:
id integer [ ] Array of stock ids OR integer with single id
not_in_warehouse_id integer Warehouse id. Stock items that are present in given warehouse will be excluded.
article string
search string Search substring in Stock names/ID/Article/Price/VAT
vat_min number
vat_max number
price_min number
price_max number
tags integer [ ] Array of stock tag ids
type [ ] Array of filter by type. Valid values: COMPONENT, COMPOSITE_PRODUCT, PRODUCT, PRESELECTION
offset integer Pagination offset
limit integer Pagination limit
sort string Sort results by fields (comma separated list of fields, prefix with `-` to sort descending). Default id, possible values: id, name, article, price, vat, units
updated_from integer Unix timestamp
updated_to integer Unix timestamp
Response format:
code integer Response status code 200
result stockItem [ ]
id integer Stock item id
name string Stock item name
article string Item article number (can be used for connection with own ERP)
type enum
["COMPONENT", "COMPOSITE_PRODUCT", "PRODUCT", "PRESELECTION"]		 Item type
price double|null Price of the item
vat double|null Item Value Added Tax. VAT is not applied for component
deposit_price double|null Item deposit fee, only for PRODUCT
deposit_vat double|null Item deposit value added tax, only for PRODUCT
units enum
["", "g", "ml", "pcs"]		 Item measurement unit, only for COMPONENT
recipe stockRecipeComponent [ ] return recipe if type is COMPOSITE_PRODUCT or null if item type is not COMPOSITE_PRODUCT or recipe not defined
tags [ ] array of assigned stock item tag id's
machine_defaults StockMachineDefault Item defaults to prefill when creating a machine product
amount_max number|null Max capacity of PRODUCT or COMPONENT in machine
amount_standart number|null Product refill level of PRODUCT or COMPONENT
amount_critical number|null Critical level of item in machine of PRODUCT or COMPONENT
refill_unit_size number|null The amount or step by which the product is refilled (PRODUCT or COMPONENT)
min_refill number|null Minimum amount needed to refill machine (PRODUCT or COMPONENT)
ingredient_line string|null EVA DTS ingredient line for PRESELECTION or COMPONENT
critical boolean|null Whether PRODUCT, COMPOSITE_PRODUCT or COMPONENT is consider critical for route planing
refillable boolean|null Whether COMPONENT is refillable
account account Client account information
id integer Account id
name string Account name
timezone string Account timezone
cost_price double|null Cost price of the item. For type PRODUCT (per 1 product) and COMPONENT (per 1000 units) only. Ignored if Cost price module not enabled.
warehouse_location string|null Warehouse location of stock item for COMPONENT, PRODUCT, PRESELECTION; displayed in Pack list.
updated_at int|null Timestamp when stock item was updated
paging Paging Paging information
total integer Total items available
offset integer Current result set page offset
limit integer Max number of items per page

Add stock product

PUT /rest/v1.8.0/stock/item

  • Description
  • Data format
  • Try it
Created new stock product.
Sample request body for adding new composite product
{
    'name':'Black Coffee',
    'article':'COFFEE_BLACK',
    'type':'COMPOSITE_PRODUCT',
    'price':1.2,
    'vat':21.00,
    'recipe':[
        {
            'component_id':123,
            'amount':15
        },
        {
            'component_id':124,
            'amount':300
        },
        {
            'component_id':125,
            'amount':1
        }
    ],
    'machine_defaults': {
        'critical': false
    }
}
