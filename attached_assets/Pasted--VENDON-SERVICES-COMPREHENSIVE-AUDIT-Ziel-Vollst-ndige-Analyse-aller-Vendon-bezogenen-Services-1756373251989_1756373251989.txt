### 1.2 API ENDPOINTS ANALYSE

#### Welche Vendon API Endpunkte werden aufgerufen:
```bash
# Suche nach API-Endpunkten in allen Vendon Services
grep -r "cloud.vendon.net" server/services/ --include="*.ts"
grep -r "/rest/v1" server/services/ --include="*.ts"
grep -r "makeRequest\|getTransactions\|getMachines\|getEvents\|getRefills" server/services/ --include="*.ts"
```

#### Identifizierte API-Aufrufe:
1. **Transaktionen**: `/stats/vends` 
2. **Maschinen**: `/machines`, `/machine/{id}`
3. **Events**: `/event/`, `/events`
4. **Refills**: `/refills`, `/refills/{id}`
5. **Stock**: `/stock`, `/machine/{id}/stock`
6. **Produkte**: `/products` (teilweise)

### 1.3 DATENBANK MAPPING

```sql
-- Vendon-spezifische Daten
```

## 8. AUDIT COMMANDS

### 8.1 Vollständige Code-Suche:
```bash
# Alle Dateien mit Vendon-Referenzen finden
find . -type f \( -name "*.ts" -o -name "*.tsx" -o -name "*.js" -o -name "*.jsx" -o -name "*.md" \) \
  -exec grep -l -i "vendon" {} \;

# Alle API-Keys und URLs finden
grep -r "cloud\.vendon\.net\|VENDON_API" . --include="*.ts" --include="*.js" --include="*.env*"

# Alle Datenbank-Queries mit vendon_id finden
grep -r "vendon_id\|vendonId" server/ --include="*.ts" --include="*.sql"

# Alle Scheduler/Timer mit Vendon-Bezug
grep -r "setInterval\|setTimeout.*vendon\|cron.*vendon" server/ --include="*.ts"
```

### 8.2 Datenbank-Analyse:
```sql
-- Alle Tabellen mit vendon_id Spalten
SELECT table_name, column_name 
FROM information_schema.columns 
WHERE column_name LIKE '%vendon%';

-- Datenvolumen pro Vendon-Tabelle
SELECT 
  schemaname,
  tablename,
  attname,
  n_distinct,
  most_common_vals
FROM pg_stats 
WHERE attname LIKE '%vendon%';

-- Aktive Vendon-Sync Jobs
SELECT * FROM sync_logs 
WHERE sync_type IN ('transactions', 'machines', 'events', 'refills', 'vendon%')
ORDER BY start_date DESC;
```
