Schritt 1: Datenmodell und API-Mapping angleichen
	1.	Feld „warehouseId“ im Backend einführen
	•	Lege in der orders-Tabelle eine neue Spalte warehouse_id an, fülle sie initial mit dem Wert von location_id.
	•	Sorge dafür, dass der API-Query /api/orders/{id} künftig neben location_id auch warehouse_id liefert.
	2.	Name des Lagers mitliefern
	•	In deinem Orders-Query die Join-Abfrage auf die warehouses-Tabelle ergänzen und das Feld warehouse_name alias warehouseName mit ausliefern.
	•	Beispiel (Postgres-SQL):

SELECT o.*, w.name AS warehouse_name
  FROM orders o
  LEFT JOIN warehouses w ON w.id = o.location_id
 WHERE o.id = $1;


	3.	Backend-API anpassen
	•	Passe in deinem orders-Router/Controller das JSON-Mapping so an, dass die Response ein Objekt liefert

{
  "id": 22,
  "orderNumber": "...",
  "warehouseId": 5,
  "warehouseName": "Hauptlager",
  …
}
