Import machines from spreadsheet

POST /rest/v1.9.0/machine/importMachines

  • Description
  • Data format
  • Try it
Request should be sent as Content-Type: multipart/form-data, file should be sent with param key file.
An empty import template file can be retrieved from GET /machines/importTemplate.
Upon successful import, response will contain an array of imported machine ids.
If validation for any record in upload file fails - none of the rows will be updated/imported. array of errors will be returned. e.g.: 
{
    'code': 200,
    'result': {
        'machine_ids': [
            101,
            102,
            103
        ]
    }
}
{
    'code': 400,
    'result': {
        'template_id': 12345,
        'errors': {
            'P6': [
                'Invalid value.'
            ],
            'O9': [
                'A number is required'
            ]
        }
    }
}

A spreadsheet with highlighted invalid cells can be downloaded from GET /machines/importTemplate by passing optional template_id parameter to it

Last full audit files in period

GET /rest/v1.9.0/machine/lastAuditFiles

  • Description
  • Data format
  • Try it
Method returns latest full audit files for machines. There are two kind of responses possible:
json - for details see responses docs.
xml - Sample response:
<?xml version='1.0'?>
    <root version='1.0'>
    <machines>
    <machine>
    <lastupdated>2017-09-09 23:12:27</lastupdated>
    <created>2017-09-10 10:56:41</created>
    <hostname>Vending machine name 123</hostname>
    <machinenumber>machine number</machinenumber>
    <product>
    <id>1</id>
    <name>Coca-cola can</name>
    <paid>25</paid>
    <free>0</free>
    </product>
    <product>
    <id>2</id>
    <name>Water</name>
    <paid>0</paid>
    <free>527</free>
    </product>
    ...
    </machine>
    ...
    </machines>
    </root>

lastupdated - EA305 (Date Of Last Read Out) EA306 (Time Of Last Read Out)
created - EA302 (Date Of This Read Out) EA303 (Time Of This Read Out)
hostname - vending machine name in Vendon cloud
machinenumber - ID101 (Machine Serial Number) or serial from Machine if not found in audit
product - Product information: 
<id>   - PA101 (Product Identifier)
    <name> - PA103 (Product Identification)
    <paid> - PA201 (Number of Products Vended Since Initialisation)
    <free> - PA401 (Number Of Free Vends Since Initialisation)

Push prices

PUT /rest/v1.9.0/machine/{id}/pushMasterPrices

  • Description
  • Data format
  • Try it
Write prices to telemetry unit. MDB Master, CCI-CSI Master or Executive Master - required.
Sample request:
{
    'override_mode': 1,
    'price_lists': {
    'pd1': [
    {
    'selection': 1,
    'price': 100
    },
    {
    'selection': 2,
    'price': 225
    },
    {
    'selection': 3,
    'price': 150
    }
    ],
    'pd2': [
    {
    'selection': 1,
    'price': 500
    },
    {
    'selection': 2,
    'price': 1000
    },
    {
    'selection': 3,
    'price': 700
    }
    ]
    },
    'type': 'scheduled',
    'time_begin':1472646139,
    'time_end':1478646100
    }

To apply these prices in Vending machine it is required to enable Vending Protocol - Master (MDB Master, CCI-CSI Master, Executive Master) with Master prices configuration (except Executive Master) enabled
  • Price 65535 - will disable selection
  • Price 65534 - will allow to use Machine price (except Executive Master)
  • Up to 100 selections supported per price list

To get actual file transfer task status, see TelemetryUnit API /telemetryUnit/{id}/sendFileStatus
! Note that time_end parameter is optional. If not set default value is one year from now.
! Note that you can't schedule multiple same type price pushes, in case of duplicate (two push tasks with same type, which are not send to unit), previous push request will be cancelled automatically.

Possible peripheral device status codes

0 not responding
1 active
2 inactive (inhibited)
3 unknown state

Possible payment status codes

512 Credit sent to machine
513 Credit timeout (Nothing selected)
514 Failed
515 Vend failed
516 Vend cancelled
517 Vend session complete (before transaction was completed)
518 Credit request saved
519 Vend successful
520 Machine is offline
521 Wrong request parameters
522 Wrong request type
523 Unknown error
524 Previous credit request active
525 Remote credit not supported
526 Remote credit cancelled
527 Credit sent: no status update from the machine within 65 seconds
