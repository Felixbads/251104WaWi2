Proviantomat – Design & CSS Styleguide

⸻

1. Farben (CI-konform)

:root {
  --proviant-rot: #8B2510;
  --kachel-rot: #C1442D;
  --kachel-orange: #D97E2E;
  --kachel-beige: #E3C9A8;
  --kachel-gruen: #6C9A78;
  --text-schwarz: #1C1C1C;
  --text-grau: #6A6A6A;
  --hintergrund: #FAFAFA;
  --weiss: #FFFFFF;
}



⸻

3. Layout & Seitenraster

.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 24px;
  display: flex;
  flex-direction: column;
  gap: 24px;
}

Sidebar (Desktop fest, Tablet ausklappbar)

.sidebar {
  background-color: var(--proviant-rot);
  color: var(--weiss);
  width: 250px;
  padding: 24px;
  position: fixed;
  top: 0;
  left: 0;
  height: 100%;
}

@media (max-width: 991px) {
  .sidebar {
    position: absolute;
    transform: translateX(-100%);
    transition: transform 0.3s ease;
  }

  .sidebar.open {
    transform: translateX(0);
  }
}

6. Tabellen

  overflow: hidden;

  padding: 12px;
  border-bottom: 1px solid #eee;

⸻

7. Diagramme

Für Diagramme empfehlen sich z. B. Chart.js oder ApexCharts, mit folgendem Stil:

colors: ['#8B2510', '#C1442D', '#D97E2E', '#E3C9A8', '#6C9A78']

	•	Hintergrund: #FAFAFA
	•	Schrift: Inter, #1C1C1C
	•	Linien weich abgerundet, Legenden in Grau #6A6A6A

⸻

8. Logos & Icons
	•	Logo-Position: oben links neben Titel (max. Höhe: 36px)
	•	Icons: Weiß auf farbigen Flächen (SVGs oder Icon Fonts)
	•	Farbflächen: Rot, Orange, Beige, Grün
