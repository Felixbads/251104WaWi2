Components usage

GET /rest/v1.9.0/stats/components

  • Description
  • Data format
  • Try it
Returns components usage for each machine, not grouped by machine and component for selected period.
Required params are from_timestamp and till_timestamp, machine_id, component_stock_id is for additional filtering
Components usage is stored in periods of 15 minutes (eg. usages from 14:00 till 14:14 will be in one result set, you can not get exact usage in time from 14:02 till 14:10)
