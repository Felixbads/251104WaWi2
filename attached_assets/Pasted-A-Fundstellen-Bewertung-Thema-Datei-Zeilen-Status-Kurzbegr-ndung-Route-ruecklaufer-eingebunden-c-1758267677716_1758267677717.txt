B) Endpoint-Spezifikation
Vendon Refills
Endpoint: GET https://cloud.vendon.net/rest/v1.8.0/refills
Query-Parameter: from_timestamp, to_timestamp, offset, limit (Sekunden seit Epoch). Optionaler Geräte-Filter nicht implementiert.
Auth: Header Authorization: Token <API_KEY>; Fallback-Key hart kodiert (Risiko).
Beispiel-Request:
GET /rest/v1.8.0/refills?from_timestamp=1716943200&to_timestamp=1719548800&offset=0&limit=500 HTTP/1.1
Host: cloud.vendon.net
Authorization: Token ****0VoB
Accept: application/json
Refill Details
Endpoint: GET https://cloud.vendon.net/rest/v1.8.0/refills/{refill_id} liefert Array oder Objekt mit added, removed, name, stock_id usw.
Mapping Vendon → intern → UI
Vendon-Feld	DB-Feld (refills/refill_details)	API-Ausgabe	Frontend-Feld
refill_date (Unix s)	refills.datetime (JS Date)	/api/removed-products → datetime	Anzeige/Tooltip (format, formatDistanceToNow)
relation_name	refills.machine_name	machineName	Tabellenköpfe/Trends
refiller	refills.operator	operator	Export-Spalte, Tabellen-Footer (andere Seiten)
name	refill_details.product_name	productName	Tabellen, Badges
removed	refill_details.removed	removed / totalRemoved	Kennzahlen & Charts
added	refill_details.added; Netto quantity = added - removed	nicht exponiert	(Derzeit ungenutzt)
stock_id	refill_details.vendon_product_id	vendonProductId	(Anzeige anderer Tabs)
price (aus Verkäufen)	via Join transactions.price	avgSalePrice/estimatedLoss in Stats	Detailkarten, Verlust-Anzeigen (nur via POST-Route)
Backend-Zusammenfassung
/api/removed-products (GET) filtert refill_details nach Datum, Maschine, Produkt; kein Paginierungs-Header.
/api/removed-products/top (POST) liefert Rangliste, aber ohne Kostenfelder (s.u.).
/api/removed-products/stats/:productName (POST im neuen Router) liefert Summen, Maschinen-Breakdown, Timeline.
/api/removed-products/location-trends (POST) kombiniert Entnahmen mit Umsatzdaten.
Zeitzone
Alle SQL-Filter arbeiten mit NOW() bzw. rohen Timestamps; es gibt keine explizite Konvertierung auf Europe/Berlin, UI rendert Browser-Locale.

    (pool.query as jest.Mock).mockReset();
  });
